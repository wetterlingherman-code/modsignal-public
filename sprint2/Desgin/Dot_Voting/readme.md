## Dot Voting

We used the Dot Voting system to choose and ideate around different kinds of protoypes for prototype 1. We defined 2 core ideas where we used the power of 10 tool, to spawn different ideas

We then posted different post-it notes with the different ideas and each member had 3 votes PER core idea (6 in total) which was voted using the "+" sign. 

## Conclusion

The 3 highest voted ideas where then selected, and each member got to write down objections to the selected ideas. This gave us a better scope with more insights instead of locking us up to some kind colletive yes-saying.
