- Functional requirements
- The system should be able to search for a specific user
- The system should be able to show an overview
- The system should be able to process a dataset and integrate in 
- The system should be able to show earlier user comments and rank them based on toxic and harmful words
- The system should be able to filter and sort data based on selected criteria
- The system should be able to store and manage user information securely.
- The system shall be able to support multiple user roles with different permissions.
- The system should be able to detect language patterns in a specific user’s history to show toxic behaviour.
- The system should be able to visualize user activity through graphs and charts.
