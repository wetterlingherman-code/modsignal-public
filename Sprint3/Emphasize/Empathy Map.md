## Empathy Map 

## Persona: 
- William Wallstedt, 44 years old.
# Role:
- One of the few active moderators in a large Swedish political subreddit. 
# Focus:
- Comment Moderation

## Says

# William expresses the following:
“It is a commitment that I choose to do voluntarily.”

“Some days it takes 30 minutes, other days it can take hours”.

“It is a very subjective judgment”.

## Thinks 

# What William might be thinking, but does not say directly: 
“Is this actually breaking the rules, or is it written in a rude tone?”

“If I remove this comment, am I censoring an opinion?”

“What I do matters for a lot of people. Not only me.”


## Does

# What william actually does as a moderator: 

William uses Reddit’s built-in moderation tools, mainly the mod queue, automated keyword flags, mod log and user notes. These tools help him see reported comments and previous actions within the subreddit. However, they do not understand context or tone, so he still has to read and judge many comments manually. 


## Pains 

# Williams main challenge:

- Lack of time 
- Subjective Decisions
- Revenge reporting 
- The voting system 
- Moderator burnout 
- Limited Tools
- Accusations of bias






## Gains

# What William will gain from a better solution:

- A lot more sustainable moderation 
- More consistency 
- Better context 
- Less manual work 
- Increased trust 
- Better public discussions
