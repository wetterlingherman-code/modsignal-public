## Projektnamn

Detta repository innehåller vårt grupprojekt i kursen Datadriven verksamhetsutveckling.

## Projektöversikt
Challenge: Political polarization and social media  
Mission: Consulting 
Problem owner / målgrupp: Polarisering inom medier och sociala medier

## Syfte
Syftet med projektet är att utveckla en datadriven produkt eller tjänst kopplad till politisk polarisering och sociala medier.

## Struktur i repot
- `docs/` – dokumentation, mötesanteckningar, intervjuer, problemformulering
- `design/` – designmaterial, skisser, prototyper
- `personas/` – personas och användarinsikter
- `data/` – rådata och bearbetad data
- `notebooks/` – analys, EDA och ML
- `src/` – kod till applikation eller prototyp
- `presentation/` – material till demo och presentation

## Arbetsprocess
Projektet genomförs enligt Design Thinking-processen och organiseras i sprintar via GitHub Project / Scrum board.
